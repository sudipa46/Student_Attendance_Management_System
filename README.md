Student Attendance Management System

Project Description:-

The Student Attendance Management System is a Python desktop application developed to simplify student attendance management. 
It provides an easy-to-use interface for maintaining student records, marking attendance, and generating attendance reports.

Features:-

- Secure Login System
- Add New Students
- View Student Details
- Mark Student Attendance
- Generate Attendance Reports
- User-Friendly Interface

Technologies Used:-

- Python
- Tkinter
- SQLite
- Visual Studio Code
- Git & GitHub

How to Run:-
1. Clone the repository:
git clone https://github.com/sudipa46/Student_Attendance_Management_System.git

2. Open the project folder.

3. Run the application:
python main.py


Project Structure:-

- main.py
- login.py
- dashboard.py
- attendance.py
- students.py
- view_students.py
- reports.py
- database.py
